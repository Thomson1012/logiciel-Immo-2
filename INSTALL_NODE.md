# 📝 Instructions d'Installation Node.js

## ✅ Étape en Cours

L'installeur Node.js v20.10.0 est maintenant ouvert sur votre Mac.

### 🔧 Suivez ces étapes dans l'installeur :

1. **Introduction** → Cliquez sur "Continuer"
2. **Licence** → Cliquez sur "Continuer" puis "Accepter"
3. **Destination** → Laissez le disque par défaut, cliquez sur "Continuer"
4. **Type d'installation** → Cliquez sur "Installer"
5. **Mot de passe** → Entrez votre mot de passe administrateur Mac
6. **Installation** → Attendez la fin (environ 1-2 minutes)
7. **Résumé** → Cliquez sur "Fermer"

### ⏭️ Après l'Installation

Une fois l'installation terminée, **revenez ici et tapez "continue"** pour que je puisse :

1. ✅ Vérifier que Node.js et npm sont bien installés
2. ✅ Installer les dépendances du projet (chart.js, jspdf, html2canvas)
3. ✅ Continuer la migration ES6 modules
4. ✅ Configurer Vite pour le build
5. ✅ Tester l'application

### 🎯 Temps Estimé

- Installation Node.js : **2 minutes**
- Installation dépendances npm : **1 minute**
- Suite de la migration : **1-2 heures**

---

**💡 Note :** Si l'installeur ne s'est pas ouvert, vous pouvez le lancer manuellement depuis :
`~/Downloads/node-installer.pkg`
